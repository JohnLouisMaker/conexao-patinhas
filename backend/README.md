# Conexão Patinhas — Backend

API do projeto Conexão Patinhas, plataforma para adoção responsável de animais.

**Stack:** NestJS + TypeScript + Prisma (em breve)

## Scripts

```bash
pnpm start          # produção
pnpm start:dev      # dev com hot-reload
pnpm test           # testes unitários
pnpm test:e2e       # testes e2e
pnpm build          # compila pra dist/
```

## Requisitos

- Node.js >= 20
- pnpm >= 12
