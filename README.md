# Conexão Patinhas 🐶🐱

Plataforma web para conectar animais disponíveis para adoção a pessoas interessadas em adotar de forma responsável.

## Estrutura

```
backend/   → API REST (NestJS + TypeScript)
frontend/  → Interface web (em breve)
```

## Stack

- **Backend:** NestJS, TypeScript, Prisma
- **Frontend:** (a definir)
- **Banco:** PostgreSQL
- **Pacotes:** pnpm

## Como rodar

```bash
# Backend
cd backend
pnpm install
pnpm start:dev
```
