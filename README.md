# Conexão Patinhas 🐶🐱

Plataforma web para conectar animais disponíveis para adoção a pessoas interessadas em adotar de forma responsável.

## Estrutura

```
backend/   → API REST (NestJS + TypeScript)
frontend/  → Interface Web (HTML + CSS + JavaScript + Tailwind CSS)
```

## Stack

- **Backend:** NestJS, TypeScript, Prisma
- **Frontend:** HTML, CSS, JavaScript, Tailwind CSS
- **Banco:** PostgreSQL
- **Pacotes:** pnpm

## Como rodar

```bash
# Frontend
cd frontend
start index.html
```

```bash
# Backend
cd backend
pnpm install
pnpm start:dev
```
